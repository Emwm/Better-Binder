Source code for "The Better Binder" an IGEN 330 capstone project by Emmett Morley, Reese Brogden, Sean Song, Steven Bowman and Tess Buckley.
ESP code should be downloaded to any ESP32 device (we used a XIAO C3 for its low profile and power management), modify pin assignments as needed.
IOS is the bulk of this repositories content. It holds all of code required to install the Better Binder app, which offers many features for tracking and maintaining healthy binding practices.
